# Rapid Recall
A simple guessing-game app that includes all the required features, as well as:
- Coloured text based on whether the user was correct, greater or lesser than the digit or has input more than enough digits for the length
- Capturing duration timestamp and mean/average statistics
- Accuracy (Rounds / total guesses, since every round is presumed to be correct)
- Screen-switching functionality through the usage of enumerations
